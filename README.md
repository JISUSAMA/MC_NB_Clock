# 🕰 지금 몇 시일까요?

> **시계 읽기 능력 향상**을 위한  
> 초등학교 1학년 대상 **3D 인터랙티브 시간 학습 콘텐츠**
> 
---

## 📌 개요

**“지금 몇 시일까요?”**는 아이들이 **아날로그 시계 읽기**, **하루 일과 시간 인식**, **시침/분침의 원리**를 직관적이고 재미있게 익힐 수 있도록 구성된 **퍼즐형 시간 학습 콘텐츠**입니다.

## 📚 학습 콘텐츠 구성 방식

### Mission01: 시계 읽기 훈련

* **퀴즈 유형**: 시계탑에 시계를 맞춰야 함 (드래그 방식)
* **정답 생성 방식**: 1\~12시, 분은 0, 15, 30, 45 중 랜덤
* **선택지 구성**: 정답 + 랜덤 보기 2개
* **UI 요소**: `QuestionText`로 "몇 시 몇 분을 찾아주세요!" 안내

### Mission02: 시간과 하루 일과의 순서 매칭

* **퀴즈 유형**: 일과 장면에 어울리는 디지털 시계 선택 (터치 선택 방식)
* **정답 생성 방식**: 미리 정의된 6개의 시각 (예: 7:15, 8:30 등) 활용
* **선택지 구성**: 정답 + 3개의 랜덤 보기, 중복 방지 처리 포함
* **UI 요소**: 퀴즈 이미지 + 텍스트 시간 표시 (`QuizImage`, `QuizTimeText`)

## 📁 프로젝트 구조 개요

이 Unity 기반 프로젝트는 아이들이 시간 개념을 쉽게 익히도록 설계된 시계탑 테마 학습 콘텐츠입니다. 주요 씬은 다음 두 가지 미션으로 나뉘며, 모두 `GameManager`, `NarrationManager`, `SoundManager` 등의 공통 관리자 클래스들과 함께 작동합니다:

1. **Mission01 - 시계 바늘 맞추기**
2. **Mission02 - 하루 일과 순서 정하기**

이 두 미션은 시각적 상호작용, 나레이션, 정답 확인 및 효과음 등 다양한 학습 요소가 통합되어 있습니다.


## 🔁 실행 흐름 요약

### 🎬 1. **인트로 씬 (`IntroManager`)**

* 🌀 타이틀 텍스트 **웨이브 애니메이션** 연출
* ✋ `"터치하여 시작"` 문구 반복 점멸
* ▶️ `Start` 버튼 클릭 시 → **Mission01 씬**으로 전환



### 🕰️ 2. **Mission01 - 시계 바늘 맞추기**

* 🎯 `Mission01_DataManager`에서 퀴즈 시작
* 🏰 시계탑의 시계를 보고, **정답 시각의 시계를 드래그**
* ✅ `WordEnter` + `TouchObjectDetector`로 **드래그-드롭 정답 판정**
* ✨ 성공 시 이펙트 + `"정답이에요!"` 나레이션 → 다음 문제
* 🔁 총 **3문제 완료 후 종료**



### 📸 3. **Mission02 - 하루 일과 시간 맞추기**

* 🧩 장면 이미지에 어울리는 시계를 선택하는 **6문제 퀴즈**
* 🎛 `Mission02_DataManager`가 전체 흐름,
  🎨 `Mission02_UIManager`가 UI 및 나레이션 제어
* 📲 시계 터치 → 바로 정답 여부 판단
* 🔁 **정답 시 다음 문제 자동 진행**, 최종 엔딩 나레이션 출력

## 🔧 주요 클래스 설명

| 클래스                                   | 역할 및 기능                                                                  |
| ------------------------------------- | ------------------------------------------------------------------------ |
| ✅ **`GameManager`**                   | 🔹 전체 게임 상태 관리<br>🔹 현재 스테이지, 터치 가능 여부, 페이드 효과 등                         |
| ✅ **`Mission01_DataManager`**         | 🔹 Mission01 메인 로직 제어<br>🔹 정답 생성, 시계 배치, 진행 흐름 관리                       |
| ✅ **`Mission02_DataManager`**         | 🔹 Mission02 전체 흐름 Coroutine 제어<br>🔹 정답 생성 및 시계 선택 UI 트리거               |
| ✅ **`TouchObjectDetector`**           | 🔹 터치 및 드래그 입력 처리<br>🔹 `Mission1` 드래그 / `Mission2` 터치 클릭 분기             |
| ✅ **`WordEnter` / `Mission02_Clock`** | 🔹 정답 판정용 컴포넌트<br>🔹 드래그 종료 (`WordEnter`) / 클릭 즉시 (`Mission02_Clock`) 처리 |
| ✅ **`NarrationManager`**              | 🔹 나레이션 출력 및 텍스트 애니메이션<br>🔹 오디오 클립과 동기화된 `ShowNarrationAuto()` 제공       |
| ✅ **`SoundManager`**                  | 🔹 BGM / SFX / VOICE 관리 및 저장<br>🔹 슬라이더 및 토글로 볼륨 설정 가능                   |
| ✅ **`UIManager` (미션별)**               | 🔹 `ClockTower` 이동, 정답 텍스트 표기<br>🔹 선택지 활성화, 타이틀 출력 등 연출 전담              |

## 📌 기타 보조 요소

* `ClockTowerCtrl`: 시계탑에 시계 설정 및 효과 파티클 제어
* `CoroutineRunner`: 코루틴 실행 및 중복 방지용 키 기반 제어 유틸리티
* `FloatObject`: 시계 오브젝트 부유 애니메이션 처리
* `SettingManager`: 3D 설정, 사운드 토글, 재시작 기능 제공
